# Extension Letter Preview

Date: 2026-03-12

## Decision

Render letter-like proposal output in the extension with a minimal preview instead of raw textarea-only display.

## Scope

- Display-only improvement.
- No backend or personalization changes.
- No new controls.
- Keep existing actions such as save, copy, PDF, and clear.

## Reason

After aligning the default output format with Proposal Forge, the main remaining coherence gap was presentation. A lightweight letter-style preview improves perceived quality without making the extension heavy or changing generation behavior.
